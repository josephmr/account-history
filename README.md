# Account History

A RuneLite plugin that tracks your OSRS account milestones and sends them to [MaxCape](https://maxcape.net).

## What it tracks

- **Skill level ups** — every time a skill reaches a new level
- **Collection log additions** — every time a new item is added to your collection log
- and more coming...

Each event is timestamped so you can see the history of how your account progressed.

## Inspiration

- **[DinkPlugin](https://github.com/pajlads/DinkPlugin)** — for the plugin architecture pattern of subscribing to RuneLite events and dispatching async HTTP notifications.
- **[Wise Old Man](https://wiseoldman.net)** — for the idea of tracking and visualising OSRS account progression over time.
